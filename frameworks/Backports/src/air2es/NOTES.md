# air2es notes

air2es translates the render stages of a Metal library (AIR bitcode) into GLSL ES 1.00
folders that the Metal backport loads. This file records what is known to be missing
and why, so it is not rediscovered later.

## Measured on Telegram's default.metallib (macOS air64, 15 modules)

- 12 of 14 render functions translate, pass the Appendix A checker, and pass
  glslangValidator in ES mode: basic_vertex, edgeTestVertex, matrixVertex,
  post_vertex_main, twoInputVertex, vertexPassthrough, edgeTestFragment, fragmentPlain,
  basic_fragment, scaleAndBlur, transformAndBlend, fragmentColorConversion.
- matrixFragment is refused by name: its sampler has a linear mipmap filter, and a
  translated texture has no mipmaps on GLES 2.
- post_fragment_main is refused: its nested loop re-enters an earlier block, and the
  structurer lowers only counted cycles (see Control flow). This comes from reading the
  CFG, not from a run.
- compute_main is a kernel and translates to a 14,597-line GLSL ES kernel, because its
  helpers are inlined at each call site. glslangValidator accepts it in ES mode. It
  needs the constexpr cube sampler and two counted loops with breaks.

## Constexpr samplers

- A constexpr sampler is an `i64` global named by `air.sampler_states` metadata, and a
  sample reads it through a pointer to that global, not through an argument.
  `samplerStateOf` in `translate.cpp` reads it, and `air2es --samplers METALLIB` prints
  the state of each function, so the table generator reads it the same way.
- The state is decoded by lookup in `samplers.inc`, generated by
  `tools/metal_sampler_table.lua` from the Metal compiler of Xcode 27B47. The table is
  for the iOS target, and it has 795 states. A state outside the table is refused by
  name, as is each part GLES 2 cannot express: mirrored repeat, clamp to zero (a linear
  filter with it is refused with the texture size an emulation would need), a mipmap
  filter, pixel coordinates, anisotropy and a LOD clamp above zero. A plain sample does
  not read the compare function, so a constexpr compare is not refused.
- The generator needs the toolchain's `metal` and `metallib`. The image is pinned in
  `tools/metal_toolchain.lua`. Run it with
  `./xmakew l frameworks/Backports/tools/metal_sampler_table.lua DMG build/macosx/arm64/release/air2es src/air2es/samplers.inc WORKDIR [MOUNT]`.
  DMG may be empty, and then `REVENANT_METAL_TOOLCHAIN_DMG` names the image. Pass MOUNT
  when the image is already attached read-only, because a second attach of the same
  image is refused.
- The table's rows are checked against the Telegram constants 0x807bff0000080a49 and
  0x807bff0000084a92: the generator stops if the compiler does not produce them.
- The reflection of a texture carries the decoded wrap and filter. The loader applies
  them at each draw, because a constexpr sampler has no MTLSamplerState to bind.
- The iOS target declares no border colour, so `clamp_to_border` does not compile for
  iOS and the table has no border field.

## Corpus check

- `./xmakew l frameworks/Backports/tools/metal_corpus.lua DMG build/macosx/arm64/release/air2es REFERENCE OUT.tsv [MOUNT]`
  compiles the Metal sources of a Telegram checkout to iOS AIR, links them per
  directory, translates each library and writes one verdict per entry point.
- On Telegram-iOS-release-13.0.0 it gives 89 entry points: 43 fragment, 27 vertex and
  19 kernel. 32 translate (18 fragment, 14 vertex); all 19 kernels are refused.

## Precision and device checks still owed

- Fragment shaders use `precision mediump float;`, as the loader contract requires.
  The `fmod` lowering (`x - y * sign(q) * floor(abs(q))`, with `q = x / y`) runs its
  quotient at mediump, so large quotients can lose integer precision. Check it on a
  device.
- The blur accumulators (scaleAndBlur, transformAndBlend) are vec4 sums of 61 samples
  at mediump. Check the result against the Metal output on a device.
- The `[[position]]` flip (`y = revenant_flip > 0 ? target.y - gl_FragCoord.y :
  gl_FragCoord.y`) is derived from the encoder's flip logic and is not verified on a
  device.

## Design choices

- A constant table read at a variable index becomes a select chain over its entries.
  An index outside the table takes the last entry. LLVM calls that case undefined, so
  the choice is ours.
- A variable read from an empty constant table is refused by name.
- A buffer read at the instance id is read as uniforms of that instance's element: the uniform carries
  `instanceStride` set to the element size, and the host offsets it by the instance of each draw. A dynamic index into an
  array member of a buffer is a select chain over one uniform per element, as for a constant table. The instance probe
  checks both on the 4S through the Metal backport.
- A square float matrix member (`float2x2`, `float3x3`, `float4x4`) is one `uniform matN`. A load of a column, or of a lane
  of one, becomes an index into it. Metal pads a column of a float3 matrix to four floats, so the host packs only the three
  floats of each column for `glUniformMatrix3fv`. The instance probe checks the column-major product on the 4S against a
  host reference, and a transposed upload must fail the same reference.
- A read of a texture at the thread position is a nearest fetch of the texel centre, with the size from the host. A
  logical shift right of a thread position, or of one of its lanes, by a constant is an integer division by 2^k. The
  texture stage of the ES 2 probe checks both on the 4S: exact for the sizes it runs, which are up to 1024 by 1024.
- Internal helper functions are inlined at each call site. They are not emitted as GLSL
  functions, so their sampler and texture parameters map to the caller's bindings.
- Control flow: an if/else region ends at the branch's immediate post-dominator. Phi
  values are copied on each edge, through temporaries when an edge copies more than one
  phi.
- A loop is lowered only when it starts at a constant, steps by one and exits when
  `index + 1` equals a constant. It becomes `for (int i = start; i < bound; i++)`.
  Two shapes qualify. A single block that branches to itself. Or a header whose
  conditional branch enters a latch that branches back to the header and exits on the
  same block as the header. In the second shape each edge that leaves the loop is a
  `break` after its phi copies, the back edge is the phi copies of the iteration, and a
  join outside the loop is the header. Any other loop is refused by name.
- Half-precision vertex attributes are refused, because the loader reads anything but
  float and i8 as a short.
- `BranchInst` is deprecated in LLVM 23.1.4, as in `air2cpu.cpp`. It is kept because the
  pinned revenant@llvm 23.1.3 cannot be checked on this machine.

## Checks

- `./xmakew l frameworks/Backports/tools/air2es_check.lua FOLDER [GLSLANG]` checks a
  folder written by `air2es METALLIB FOLDER`. It checks `library.json`, every
  function's reflection against its source, and the Appendix A limits. It runs
  glslangValidator as a separate gate, and reports how many functions pass each. A
  function counts only when both pass.
- `frameworks/Backports/tools/air2es_limits.lua` implements the Appendix A checks. The
  rules come from GLSL ES 1.00, Appendix A, section 4 (loops) and section 5 (indexing),
  revision 17.
- `./xmakew l -P frameworks/Backports frameworks/Backports/tests/air2es_test.lua` runs 15
  checker cases. It is registered as the `air2es` suite of the backports tests.
- Negative control: replacing a loop bound with `int(inputTexture_size.x)` in the
  scaleAndBlur output keeps glslangValidator at exit 0, and the checker refuses it.
- The Telegram oracle is an external file, so the harness run on it is not part of CI.
  Whether it may run in CI is an owner decision.
