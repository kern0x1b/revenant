# CoreMIDI: RevenantCoreMIDIProtocols.h

## RevenantCoreMIDIProtocols.h

The header is generated by `xmake l tools/gen.lua protocols` from `spec/CoreMIDI/protocols.tsv` and
`spec/protocol-headers.tsv`. The comments the committed header carried, in its order, are kept here:

```text
Revenant's declarations of the MIDI-CI protocols of the CoreMIDI backports: the responder's delegate of MIDI-CI 1.x, which the
protocol-sources gate reads (tests/addon/protocol-sources.sh). The initiator identifier is declared here as well, because
the protocol names it and the classes header imports this one.
```
